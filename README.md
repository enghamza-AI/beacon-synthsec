## What is this

Beacon is a synthetic-data demo of [SynthSec's](#author) subscription health methodology: it scores every account 0-100 on churn risk, flags the most likely reason, and groups accounts into health segments (healthy, at-risk, dormant, new) — instead of finding out someone was unhappy the day they cancel.

This is a portfolio piece, not a client deliverable. All data is synthetic and clearly labeled as such.

## The problem

Usage almost always declines quietly for weeks before a cancellation — fewer logins, narrower feature use, more support tickets — but most teams have no systematic way of watching that trend per account. By the time someone notices, the account has already cancelled.

## What it does

```
synthetic weekly usage CSV
        │
        ▼
  pandas cleaning              → drop bad rows, require minimum history
        │
        ▼
  feature engineering          → recent-vs-prior usage trend deltas per account
        │
        ▼
  K-Means segmentation         → healthy / at-risk / dormant / new (unsupervised)
        │
        ▼
  churn-risk classifier        → RandomForestClassifier predicts churn probability (supervised)
        │
        ▼
  recommended actions          → plain-English next step + urgency, per account
        │
        ▼
  Streamlit dashboard          → deployed on Hugging Face Spaces
```

## Key concepts

| Concept | 
|---|---|
| Trend features | Recent vs. prior 4-week usage windows, compared as a percent change — not raw levels |
| K-Means health segmentation | Unsupervised clustering into 4 tiers, named by ranking cluster centroids relatively |
| RandomForestClassifier | Predicts churn probability per account, scaled to a 0-100 risk score |
| Class imbalance handling | Stratified train/test split + `class_weight="balanced"`, since churn is the minority class |
| Rule-based reason flagging | Each risk score comes with the single most explanatory signal, in plain English |

## Dataset

100% synthetic, generated by `src/synthetic_data.py`. A subset of accounts are secretly assigned a declining engagement trajectory (exponential decay with noise); cancellation triggers once decayed engagement crosses a threshold. This produces a genuinely learnable churn signal that has to be recovered from noisy weekly counts, not a trivially separable toy dataset.

## Results

Numbers from the bundled demo dataset (2,000 synthetic accounts):

| Metric | Value |
|---|---|
| Accounts scored | 1,953 |
| Segments found | 4 (healthy, at-risk, dormant, new) |
| Silhouette score | 0.26 |
| Churn-risk model ROC-AUC | 0.96 |
| Accounts that churned within the observation window | ~7% |
